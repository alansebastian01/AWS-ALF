Yes. ✅ For that question, the correct order from **LEAST → MOST development effort** is:

**1. Prompt engineering**
↓
**2. Retrieval Augmented Generation (RAG)**
↓
**3. Fine-tuning**
↓
**4. Continued pre-training**

The logic is:

**Prompt engineering** = just change the instructions → **RAG** = add an external knowledge retrieval system → **Fine-tuning** = actually train model parameters → **Continued pre-training** = much larger-scale additional training.

For the exam, memorize:

> **Prompt → RAG → Fine-tune → Pre-train** 🔥
